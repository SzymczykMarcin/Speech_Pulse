# Sound Sources

The current app sounds are edited from Freesound source files provided by the
project owner as CC0 inputs.

CC0 does not require attribution, but the source records below are kept for
release provenance and future review.

## Runtime Assets

- Runtime asset: `assets/sounds/hotel_bell.wav`

- Freesound title: `reception bell1.mp3`

- Source URL: https://freesound.org/s/96521/

## Release Checklist

- Confirm each Freesound page is still marked Creative Commons 0 before release.
- Save screenshots or PDF copies of the source pages in private release records.
- Keep the edited runtime files in `assets/sounds/`.
- Do not commit raw source downloads unless the project intentionally starts
  tracking third-party source material.
